name: integrate
description: Integrate working changes into commit history
---

## Problem

The changes in the working directory need to be applied in the appropriate place in the commit history.

## Instructions

- Perform an interactive rebase of the branch.
- Apply the changes present in the working directory into the commits where they should logically be placed.
- Create new `fix` or `refactor` commits as needed.
- Update the commit messages of amended commits with the changes.
- Complete the rebase.
